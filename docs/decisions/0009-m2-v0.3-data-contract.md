# 0009 — M2 v0.3 benchmark data contract

## Context

The complete v0.2.0 diagnostic executed all 80 authored paths and exposed benchmark defects rather
than system performance: swap minima were disconnected from pinned quotes, third-party absolute
balances were synthetic, two Permit2 SignatureTransfer cases named the wrong spender, Aave goals
ignored rounding and variable-debt interest, and three lending fixtures funded only the final net
debit instead of every ordered prefix.

## Decision

Version 0.3.0 is a data-contract correction. It does not reinterpret or overwrite v0.2.0 evidence.

1. Every base swap carries a `quoteReferences` entry derived from the already captured QuoterV2
   result at the fixture block. The record pins block/hash, quoter/codehash, pool/codehash, path,
   amount and output. With maximum slippage `b` basis points, calldata minimum output is exactly
   `ceil(quote * (10000 - b) / 10000)`. The current dataset uses `b = 100`.
2. Completion references use signed account-side deltas. The oracle supports `EXACT`, `AT_LEAST`
   and `AT_MOST`; generated zero-origin pre/post rows are only an offline fixture representation.
   Router, pool, aToken and bridge-contract balances are not authored as public truth.
3. AP-04 and AP-08 model Permit2 SignatureTransfer with the transaction caller/account as spender.
   The one-use signature is not represented as a stored Permit2 allowance. The underlying ERC-20
   approval to Permit2 remains execution setup evidence, not a final authorization goal.
4. Aave position minima use one chain-independent rule: modeled net position minus one atomic unit
   per position-changing supply/withdraw action. This is an authored tolerance, not an
   observed-case lookup.
5. Variable debt reserves one basis point of total borrowed principal, rounded up and at least one
   atomic unit. Explicit principal-only requests repay the stated amount and permit residual debt
   up to nominal residual plus this buffer. Semantic full-debt completion uses
   `repay(type(uint256).max)`, finite approval/funding of remaining principal plus the buffer, and a
   zero-debt final goal.
6. Starting account balances equal the minimum funding required at every ordered effect prefix.
   This corrects LE-09, LE-10 and LE-15 at the authored fixture source; runtime correction is no
   longer an accepted substitute.

## Consequences

- The 80 bases, 15 mutations, split manifest, schemas and blind review packets are regenerated as
  0.3.0.
- `HIDDEN_TEST` remains a public legacy split name. The manifest stays `frozen: false`; no unseen
  holdout claim is made.
- The v0.2.0 diagnostic remains immutable and is used only as defect-discovery evidence. v0.3.0 has
  zero current executions until a clean run produces a version-matched evidence artifact.
- Expected fixtures, executed fork evidence, model baselines, and human review remain separate
  gates. No reviewer submission or adjudication is generated automatically.
