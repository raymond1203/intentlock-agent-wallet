# Notion 편집본의 GitHub 동기화

기준일: 2026-09-14. 사용자가 노션 편집을 마친 뒤 공개 저장소 갱신을 요청한 범위의 작업이다.
대회 제출 완료나 독립 인간 검수 완료를 의미하지 않는다.

## 현재 읽을 원고

- [국문 편집본](../../paper/submission-ko.md): 노션의 제목, 본문, 문장 내 출처, 표와 캡션을 반영했다.
- [무결성 기록](../../artifacts/submission-ko-manifest.json): `NOTION_EDITORIAL_MIRROR` 형식으로 편집 출처와 파일 해시를 기록했다.
- 이미지: `figures/editorial/`의 PNG 4장. 기존 노션 첨부를 바이트 변경 없이 저장했다.

본문을 다시 쓰거나 새 그림을 생성한 동기화가 아니다. 표 9개의 데이터 32행, 참고문헌 14개와
본문·표·참고문헌의 링크 62개를 노션 원본과 대조했다. 원고를 구성하는 메타데이터 다음의
176개 블록을 순서대로 옮겼으며, Markdown의 이스케이프·표 정렬과 이미지 상대 경로만 변환했다.
그림 안의 설명은 편집 시각자료이지 새로운 실험 증거가 아니다.

대회용 EVM 주소와 학회 코드는 공개 사본에서 공란으로 두었다. 노션 페이지 주소, 블록 식별자,
첨부의 만료 URL과 전체 원본 응답은 커밋하지 않는다. 참가 인원 2명과 MetaMask 트랙만 유지한다.
공개 사본의 재현용 GitHub 링크는 유지했으므로 이 사본을 익명 제출 완료본으로 간주하지 않는다.

## 변경하지 않은 자료

`paper/final-source.md`, `paper/final.md`, `paper/tables/`, 원래 분석 그림과 `figures/ko/`,
동결 설정, 원시 실험 기록, 연구 구현 및 의존성은 그대로 보존했다. 이전 국문화 산출물과 절차는
커밋 `7d586b330e145423fd50bc313094cd3860239170`에서 추적할 수 있다.

기존 국문화 변환기를 다시 실행한 것이 아니므로, 그 변환기의 번역 횟수나 원본 그림 기하 보존
주장을 최신 편집본의 제작 근거로 재사용하지 않는다. 과거의 분석 해시도 새 실험 결과처럼 갱신하지 않는다.

## 검증 범위

저장소 루트에서 다음 읽기 전용 검사를 실행한다.

```text
node docs/experiments/audits/verify-submission-bundle.mjs
```

이 검사는 분석 조립본, 최신 편집본, 원시 기록과 별도 복구 결과의 파일 연결을 확인한다.
이전 조립본에 고정됐던 출처 순서와 33행 표 형식 대신, 검토된 노션 편집본의 출처 순서와
32행 표를 검사한다. 본문의 수치는 바꾼 것이 아니며, 시간·비용 상세표는 연결된 분석 자료로
옮기고 가드 모드 차이 분석을 추가했으며 재계획 표의 비대응 정상 사례 행을 제거한 결과다.
대회용 주소·코드 공란, 비공개 페이지 주소 부재, PNG 해시·크기와 금지 형식도 확인한다.

주 비교의 최초 평가 2,000건과 HTTP 429 실패 92건은 그대로다. 별도 재시도에서 확보한 응답을
주 결과에 덮어쓰지 않았다. 이 동기화는 새 모델 호출이나 새 온체인 실행 검증을 수행한 것이 아니다.

노션의 2026-09-14 화면에서 7,089단어를 확인했다. 로컬 단어 수 추정과 실제 노션 표시값은
같은 계산이 아니며, 저장된 화면 확인 기록은 향후 편집 후의 단어 수까지 보장하지 않는다.
최종 저자 승인, 익명성 판단, 댓글 권한과 실제 제출 여부는 저장소 밖의 확인 항목으로 남긴다.
