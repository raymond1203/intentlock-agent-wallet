# 제출 전 점검 — 2026-09-12

## 판정과 범위

연구용 구현과 원고의 재현 경로를 보완했다. 운영 MetaMask의 안전성 인증이나 전체 저장소의 줄 단위 보안 감사는 아니다. 이번 점검은 구성요소별 역할·검증 경계, 전체 회귀 검사, 고정 결과의 독립 재집계, 원고와 그림의 일치에 집중했다. 유료 모델 호출과 외부 포크 실험은 새로 실행하지 않았다.

최신 읽기용 원고는 `paper/final-review-ko.md`다. 분석 원본, 기존 제출판, 편집판, visual-v2는 동결 연결을 유지하며 덮어쓰지 않았다. 최종 저자 승인과 실제 제출은 여전히 별도다.

## 수정한 사항

1. **출판 재현 경로:** sharp 미선언과 개인 캐시 경로 때문에 다른 환경에서 그림을 재생성하기 어려웠다. 고정 의존성과 `pnpm publication:rebuild`를 추가했다. 동결된 기존 생성기는 직접 바꾸지 않고 임시 복사본의 의존성 로더만 연결한다. 원본 미변경, 의미 출력 19개 일치, 이 컴퓨터에서 PNG 16개 모두 바이트 일치를 확인했다. 다른 OS·글꼴에서는 새 PNG의 육안 검수가 필요하다.
2. **실행 경계 회귀 검사:** 응답 불명의 실행을 실패로 오인해 예약을 풀면 중복 실행 위험이 있다. 기존 보수적 동작을 바꾸지 않고 3개 테스트를 추가했다. 같은 계약으로 여러 개별 요청을 계속 처리하는 작업 세션 구현은 여전히 후속 과제다.
3. **공식 기능과 연구 기여 구분:** 도입부의 100/60 예시는 MetaMask에 누적 한도가 없다는 주장으로 읽힐 여지가 있었다. 공식 24시간 한도를 먼저 명시하고 작업별 자산·권한·최종 상태 검증을 연구 범위로 분리했다.
4. **결과 해석:** 토큰 사용 비용은 청구서 검증 금액이 아닌 추정액으로 명확히 했다. 자동 음의 결과 목록이 비어 있는 것과 실제 남는 위반·완료율 정체를 구분했다. 결론을 관측된 이력 제거 효과에 연결했다.
5. **기록과 현재 상태:** README·기여 안내를 실제 연구 단계와 1명 인간+AI 보조 검토에 맞췄다. 개인 메타데이터·승인·제출 사실은 대신 작성하지 않았다.

## 검증 기록

- 전체 검사: formatting, lint, typecheck 통과. 테스트 654개 통과, 조건부 12개 생략. Solidity 테스트 4개 통과.
- 스키마·benchmark·M2 증거·400개 평가 사례 구성 검사 통과. M2의 최종 인간 승인 상태는 PENDING이며 이를 완료로 바꾸지 않았다.
- `publication:verify`: 동결 제출판 47개, 편집판 30개, visual-v2 28개 파일 연결과 최종 개정판 일치 검사 통과.
- 독립 재집계: 주 평가 최초 시도 2,000개와 전체 시도 2,092개 구분. 8개 제거 조건 및 서명 경계 40회·160개 계획·실행기 호출 0 확인. 새 실험은 아님.
- 그림의 비율·분모·신뢰구간 및 오류 분류와 위반 허용 지표의 차이를 확인. 변경하지 않은 그림은 기존 육안 검수와 동일 바이트 증거를 재사용했고, 구조·보안/완료·오류 그림은 다시 열어 확인했다.
- 기존 Notion에는 9개 문단만 갱신했다. API 대조에서 나머지 175개 블록과 표·그림을 보존했다. 브라우저의 오래된 표시를 새로고침한 뒤 최신 제목·개정 문단·표 9개·그림 6개 로딩을 확인했다. 전체 모바일·로그아웃 화면 검수는 수행하지 않았다.

## 종료 전 남는 사항

공유 화면에서 웹의 모든 사용자에게 **편집 허용**이 설정된 것을 발견했다. 외부 수정 방지를 위해 **댓글 허용**으로 제한했고 변경된 권한 표시를 확인했다. 소유자의 편집 권한은 유지했다. Notion 작업 메뉴의 실제 단어 수는 **6,803개**였다. 이 확인은 로그아웃 상태의 신원 노출 검사나 실제 댓글 작성 시험을 대신하지 않는다.

- #55의 마감 정정은 변경 범위와 통과한 CI를 확인했다. 현재 운영 마감은 팀이 확인한 **2026-09-13**이며 정확한 제출 시각은 별도로 확인해야 한다. 과거 동결 자료의 9월 6일 기록은 역사적 기록으로 유지한다.
- #35는 최종 저자 승인·익명 정보 검수·제출 증빙이 남아 있으므로 자동 종료하지 않는다.
- 팀 EVM 주소와 학회 코드는 공유 채팅이나 저장소에 올리지 않고 팀이 제출 페이지에서 입력·검증한다.
- 원고를 추가 수정하면 단어 수와 댓글 권한을 재확인한다. 로그아웃 접근과 신원 노출 여부는 실제 제출 화면에서 별도 확인해야 한다. AI의 문서·수치 점검은 최종 저자 승인을 대신하지 않는다.
- Admin에게 실제 전달하거나 접수 확인을 수행하지 않았다.

## 추가 보완 — 기존 누적 유출 검사와의 기여 구분

위의 9개 문단·표 9개·6,803단어는 이 문서의 최초 검토 시점 기록이다. 이후 요청에 따라
`guard-differential-analysis.md`의 사례별 대조를 추가하고 현재 검토판을 갱신했다.

- 같은 사례 400쌍의 최초 시도와 해시를 확인했다. Guard 모형은 이미 147건을 보류했고 그중 54건에 누적 유출 초과 사유가 있었다.
- Guard 대비 83건 차이를 최초 사유로 분해했다: 가스 52, 재실행 12, 슬리피지 10, 권한 상한 8, 체인별 대상 1. 이력을 쓰지 않는 호출별 정책도 재실행 12건을 제외한 71건을 같은 사유로 거부했다.
- 호출별 정책 대비 56건 차이는 재실행 인식 41, 누적 유출 15건이다. 동일 승인 재설정도 포함되므로 실제 이중 지출 방지 건수로 표현하지 않았다.
- 핵심 요약·기여 문단·결론·후속 비교 조건을 고치고 6.1.4절을 추가했다. 기존 표 9개·자료 행 33개는 보존하고 표 1개·자료 행 5개만 추가했다. 그림 6개와 참고문헌 14개는 동일하다.
- Notion의 5개 영역을 부분 갱신한 뒤 전체 본문을 계획한 변경과 대조했다. 공백과 임시 이미지 URL의 서명 쿼리를 정규화한 비교에서 나머지 본문·표·이미지·개인 정보 공란이 보존됨을 확인했다. 백업은 저장소 밖에 보관했다.
- 최신 브라우저에서 6.1.4절과 표의 줄바꿈·가독성을 확인했다. Notion 작업 메뉴의 실제 단어 수는 **7,302개**로 제한 13,000개 미만이다. 이전 6,803개는 개정 전 수치다.
- 공유 화면에서 링크가 있는 웹 사용자에게 **댓글 허용**이 유지됨을 읽기 전용으로 재확인했다. 최종 로그아웃 익명성 검수와 실제 제출은 대신하지 않았다.
- `publication:verify`, 80개 기본 사례에서 생성하는 400개 manifest 일치, 변경 감사 코드의 lint와 전체 formatting 검사를 통과했다. 원시 결과나 판정 구현을 바꾸지 않았고 유료 모델·RPC 실험은 재실행하지 않았다.

이 보완은 비교의 해석을 강화한 것이며, 동등한 규칙을 적용한 새 비교 실험과 최종 인간
저자 승인은 여전히 수행한 것으로 표시하지 않는다.
